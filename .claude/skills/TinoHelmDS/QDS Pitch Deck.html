Opening

A terminal that
doesn't feel cold.

Trading surfaces are either bright marketing sites dressed up as dashboards, or black Bloomberg clones built in the 90s. QDS Warm sits between them — the density and discipline of a terminal, the warmth and restraint of modern writing tools.

Rigor

Numbers first.

Every data point is monospaced. Typography is the primary hierarchy — not color, not shadow.

Warmth

Warm charcoal ground.

Never pure black. The base is warm graphite with a single burnt-orange accent carrying brand weight.

Restraint

One accent. Three surfaces.

Four text steps, three border steps. The system's power comes from what it refuses to include.

Five principles

The rules we don't break.

01

Data is monospaced.

Prices, IDs, timestamps, badges. Never sans-serif for a number.

02

One accent only.

Burnt orange #D97857. Everything else is neutral or semantic.

03

Green up. Red down.

Semantic colors reserved for gain/loss, done/failed. Never decorative.

04

Surfaces, not shadows.

Elevation via 4 warm-gray steps. Shadow used only for overlay and hover-lift.

05 · The Big One

No filler. No slop.

No decorative gradients. No stock illustration. No emoji. No 300ms spring bounce. No rounded-corner-with-left-accent-stripe hero cards. If it doesn't carry information, delete it.

"One thousand no's for every yes."
the single most-quoted QDS rule in review

Signature pattern

The 3px status stripe.

Chart rules · the 10 commandments

Ten rules, applied everywhere.

The chart system is Recharts-based. These rules aren't style preferences — they're enforced in shared defaults every chart imports.

  1. Monospaced tick labels. Always. Never sans.
  2. No axis line on top or right. Bottom and left only.
  3. Horizontal grid only. Time already implies vertical structure.
  4. Grid is whisper-faint. 5% alpha. Data carries the eye.
  5. One primary color per chart. Use --acc. Semantic reserved for up/down.
  1. Gradients are rare. Only equity/drawdown area fill.
  2. Tooltip is a card. Same surface as every other card.
  3. Dots off by default. Only show on hover via activeDot.
  4. Candlestick: green up, red down. Western convention.
  5. Reference lines are dashed accent. For means, thresholds, entries.
