# QDS Trading Terminal — Design Specification

## 核心设计决策

### Sandbox / Live 不拆页面

**理由：**
- 数据结构 100% 相同（持仓、订单、策略、风控），拆页面 = 代码全部写两遍
- 用户需要频繁对照两个环境（沙盒验证 → 实盘部署），同一页面切换更快
- 拆页面后 sidebar 会多一个入口，增加导航复杂度

**安全措施：**
用颜色系统级区分，让用户不可能搞混当前环境。

## 环境标识系统

### 全局 Environment Bar

固定在页面最顶部，Content area 之上。

| 环境 | 条背景 | 文字色 | CSS 变量 |
|------|--------|--------|----------|
| **Sandbox** | `var(--info-d)` 蓝底 | `var(--info)` 蓝字 | `--env-color: var(--info)` |
| **Live** | `var(--dan-d)` 红底 | `var(--dan)` 红字 | `--env-color: var(--dan)` |

### Bar 内容

```
┌─ Environment Bar ────────────────────────────────────────────┐
│  SANDBOX   [● 沙盒] [● 实盘]     模拟环境 · 不会产生真实交易  │
│  LIVE      [● 沙盒] [● 实盘]     真实交易环境 · 所有操作将产生实际损益  │
└──────────────────────────────────────────────────────────────┘
```

### 切换到 Live 的确认

点击"实盘"按钮时弹出 `confirm()` 对话框：
> "切换到实盘环境，所有操作将产生真实交易。确认切换？"

生产版本应替换为 Danger 级 Modal（输入确认文本）。

### 环境 Tag

标题旁边有一个彩色 pill badge：
- Sandbox: 蓝底蓝字 `SANDBOX`
- Live: 红底红字 `LIVE`

## 页面结构

### Top Section

```
┌──────────────────────────────────────────────────────────┐
│  交易终端 [SANDBOX]            ● 已连接  19:56:53        │
│                                [⏸暂停] [⇄全部平仓] [◼停止] │
└──────────────────────────────────────────────────────────┘
```

**操作按钮分级：**

| 按钮 | 样式 | 级别 |
|------|------|------|
| ⏸ 暂停/▶ 恢复 | `btn-ghost` | 普通，可反复切换 |
| ⇄ 全部平仓 | `btn-warn` 黄色边框 | 警告级，触发 Warning Modal |
| ◼ 停止 | `btn-danger` 红色边框 | 危险级，触发 Danger Modal |

### Tab 导航

从 9 个 tab 精简到 **6 个**：

| 原始 Tab | 处理 |
|----------|------|
| 沙盒 / 实盘 | → 移到 Environment Bar |
| 概览 | → 保留，重命名"概览" |
| 订单 | → 保留 |
| 策略 | → 保留 |
| 风控 | → 保留 |
| 行情 | → 移到独立的 Watchlist 页面 |
| 日志 | → 保留 |
| 回测对比 | → 移到 Backtests 页面 |
| 沙盒设置 | → 移到 Settings 页面 |

Tab 后面带实时计数 badge：`持仓 (5)` `订单 (12)`

## Tab 内容

### 概览 Tab

最重要的 tab，一屏看全貌。

```
┌─ KPI (5 col) ────────────────────────────────────────────────┐
│  [总权益]  [已实现PnL]  [未实现PnL]  [持仓数]  [今日成交]     │
└──────────────────────────────────────────────────────────────┘
┌─ Charts (2 col) ─────────────────────────────────────────────┐
│  [权益曲线 30d]              [实时 PnL today]                 │
└──────────────────────────────────────────────────────────────┘
┌─ 策略列表 (table) ───────────────────────────────────────────┐
│  ▎ MM-perp v3.2 [Running]  Binance  BTC-PERP  +$820  →       │
│  ▎ Stat-arb v1.8 [Running] Hyper.   ETH/BTC   -$120  →       │
│  ▎ Funding arb [Running]   Binance  BTC-PERP  +$540  →       │
│  ... 可扩展到 10+ 策略                                         │
└──────────────────────────────────────────────────────────────┘
┌─ 最近成交 table ─────────────────────────────────────────────┐
│  Time | Strategy | Symbol | Side | Price | Size | PnL         │
└──────────────────────────────────────────────────────────────┘
```

**策略列表（表格形式）：**
- 复用回测列表的设计语言：左侧 3px 状态边（绿=running 盈利，红=running 亏损，灰=stopped）
- 列：策略名+状态badge / 交易所 / 品种+timeframe / PnL / 已实现 / 未实现 / 持仓数 / 成交数 / →箭头
- 每行可点击 → 进入策略详情面板
- 10+ 策略也不会撑爆布局，行高紧凑一致

### 持仓 Tab

```
┌─ KPI (4 col) ──────────────────────────────────────────── ┐
│  [多头持仓 3 +$820]  [空头持仓 2 -$1200]  [市值]  [保证金]  │
└──────────────────────────────────────────────────────────┘
┌─ Positions table ────────────────────────────────────────┐
│  Symbol | Strategy | Side | Size | Entry | Mark | PnL |   │
│  PnL% | Liq.Price | [平仓]                               │
└──────────────────────────────────────────────────────────┘
```

- Mark Price 列每 2 秒 tick flash（绿涨红跌）
- PnL 实时重算
- 每行右侧"平仓"按钮，hover 变红
- 多空持仓卡片分别显示总 PnL

### 订单 Tab

- KPI: 挂单中 / 已成交 / 成交率 / 平均延迟
- 表格列: Time / Strategy / Symbol / Side / Type(badge) / Price / Size / Filled%(迷你进度条) / 撤单按钮
- Order Type 用小 badge: `Limit` `Post-only` `Stop`

### 策略 Tab

纵向策略卡列表，每个策略一行：
- 左：Toggle + 名称 + Exchange · Symbol · Timeframe · N positions
- 右：PnL + Running/Stopped badge

### 风控 Tab

- KPI: 日亏损限额使用 / 最大持仓使用 / 杠杆 / 状态
- 仪表图（Gauge bars）：水平进度条展示各限额的使用百分比
  - <30% 绿 / 30-70% 黄 / >70% 红

### 日志 Tab

Terminal 风格日志展示：
- `var(--bg-in)` 深色背景
- Mono 字体，行高 1.8
- 交替行背景 `var(--bg-t)`
- 日志级别颜色：`[INFO]` dim / `[FILL]` 绿或红 / `[WARN]` 橙 / `[ERR]` 红 / `[RISK]` 白

## 实时数据行为

| 数据 | 更新频率 | 动效 |
|------|----------|------|
| Mark price | 每 tick（~100ms-2s） | 600ms tick flash |
| PnL | 跟随 mark price | 同步更新，无独立动效 |
| KPI 卡 | 每 5s | 数字渐变（CSS transition） |
| 权益曲线 | 每 1 min | 新点推入，Chart.js update() |
| 实时 PnL | 每 tick | 流式折线图 |
| 订单状态 | WS 推送 | 行闪烁后更新 |
| 日志 | WS 推送 | 新行从顶部插入，slide down 280ms |

## 与原设计的对比

| 维度 | 原设计 | QDS 重设计 |
|------|--------|-----------|
| 环境切换 | Tab（可误触） | Environment Bar + 确认弹窗 |
| Tab 数量 | 9 个 | 6 个（3 个分散到其他页面） |
| 操作按钮 | 跟 Tab 混排 | 独立 Action Bar 在标题旁 |
| 空状态 | "暂无持仓" | 引导性空状态（策略建议） |
| 配色 | 深蓝/青色 | QDS Warm（暖灰+橙 accent） |
| 数据闪烁 | 无 | 600ms tick flash |
| 环境标识 | 仅 Tab 高亮 | 全页颜色系统 + 顶部 Bar + Title Badge |

## 策略详情面板（新增）

### 入口

概览 tab 的策略卡片可点击，hover 时右侧出现 `→` 箭头 + 卡片上浮 2px + 边框变 accent。

### 进入方式

点击策略卡片 → 主内容区 + tab 栏全部隐藏 → 策略详情面板从右侧滑入（translateX 30→0, 350ms）。顶部"← 返回总览"按钮回到聚合视图。

### 详情面板结构

```
┌─ Header ─────────────────────────────────────────────────────┐
│  [← 返回总览]  MM-perp v3.2                                  │
│                Binance · BTC-PERP · 15min                     │
│                                    [Running] [Toggle] [配置] [停止] │
└──────────────────────────────────────────────────────────────┘
┌─ KPI (5 col) ────────────────────────────────────────────────┐
│  [策略PnL]  [已实现]  [未实现]  [持仓数]  [成交量]             │
└──────────────────────────────────────────────────────────────┘
┌─ Charts (2 col) ─────────────────────────────────────────────┐
│  [策略权益曲线 30d]           [今日 PnL]                       │
└──────────────────────────────────────────────────────────────┘
┌─ 持仓表 ─────────────────────────────────────────────────────┐
│  Symbol | Side | Size | Entry | Mark | PnL | PnL% | [平仓]   │
│  ← 只显示该策略的持仓                                         │
└──────────────────────────────────────────────────────────────┘
┌─ 最近成交 ───────────────────────────────────────────────────┐
│  Time | Symbol | Side | Price | Size | PnL | Latency          │
│  ← 只显示该策略的成交                                         │
└──────────────────────────────────────────────────────────────┘
┌─ 运行参数 ───────────────────────────────────────────────────┐
│  spread_bps: 2.5  |  order_size: 0.5 BTC  |  layers: 3       │
│  ← key-value 网格，同 backtest config 组件                     │
└──────────────────────────────────────────────────────────────┘
```

### 与聚合视图的关系

| 聚合视图 | 策略详情 |
|----------|----------|
| 全部策略的 KPI 汇总 | 单策略 KPI |
| 全部策略的权益曲线 | 单策略权益曲线 |
| 持仓表显示"策略"列 | 持仓表不显示"策略"列（冗余） |
| 日志显示所有策略 | 成交列表只显示该策略 + 延迟列 |

### 聚合视图 vs 详情面板

- **聚合视图**：概览 tab 展示所有策略的汇总数据，持仓/订单表包含所有策略的数据，通过"策略"列区分
- **详情面板**：点击策略卡片进入，只展示该策略的独立 KPI、图表、持仓、成交、参数配置
