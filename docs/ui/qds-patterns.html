04 — Data staleness
数据时效性指示
盯盘场景下，必须让用户知道数据是否过期。断连时显示全局告警条，过期数据变灰并标记 stale。

三级时效标记
Live 实时数据正常（<2s）
Stale 数据过期（2-30s），数字变灰斜体
Disconnected 断连（>30s），整行半透明
