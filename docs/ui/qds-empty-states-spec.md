# QDS 空状态设计规范

## 设计哲学

空状态不是"没有数据"的告知，是**引导用户走向下一步**的机会。

三条原则：

1. **告诉用户为什么是空的** — 区分"还没创建"和"出了问题"，用户的心理预期完全不同
2. **告诉用户下一步做什么** — 每个空状态必须有 action，哪怕只是一个链接
3. **不要让用户觉得系统坏了** — 空状态的视觉质量要和有数据时一样高

## 空状态分类

| 类型 | 触发条件 | 情绪 | 设计重点 |
|------|----------|------|----------|
| **首次使用** | 该功能从未产生过数据 | 期待 | 引导 + 教育，告诉用户这个功能能做什么 |
| **筛选无结果** | 用户主动筛选/搜索后无匹配 | 困惑 | 快速恢复，一键清除筛选 |
| **数据清空** | 有过数据但被删除/过期 | 中性 | 简短说明 + 重新开始的 CTA |
| **加载失败** | 网络错误/服务异常 | 焦虑 | 明确错误原因 + 重试 + 错误码 |
| **功能未配置** | 需要前置步骤（如先配置 API key） | 受阻 | 引导去完成前置步骤 |

## 视觉结构

```
┌──────────────────────────────────┐
│                                  │
│          [图标 / 插图]            │   48-56px, 圆角方块背景
│                                  │
│          主标题                   │   0.9rem, font-weight 600
│          描述文字                 │   0.78rem, var(--t2), max-width 360px
│                                  │
│          [主 CTA 按钮]            │   accent 色, 对应下一步动作
│          辅助提示                 │   0.68rem, var(--t3), 补充信息
│                                  │
└──────────────────────────────────┘
```

### 尺寸规则

| 上下文 | 垂直 padding | 图标大小 | 说明 |
|--------|-------------|----------|------|
| **全页空状态**（页面唯一内容） | `4rem 2rem` | 56px | 回测列表为空、策略列表为空 |
| **区域空状态**（页面局部为空） | `2.5rem 2rem` | 40px | 持仓表为空、策略列表中某策略无版本 |
| **表格空状态**（表格无数据行） | `2rem 1.5rem` | 不需要图标 | 订单表无挂单、成交记录为空 |

### 图标

不用 emoji，不用复杂插图。用单个简洁字符放在圆角方块背景里：

| 场景 | 图标 | 背景色 |
|------|------|--------|
| 首次使用 | `⧖` `◫` `⟐` 等页面对应图标 | `var(--bg-t)` |
| 搜索无结果 | `⊘` | `var(--bg-t)` |
| 加载失败 | `!` | `var(--dan-d)` |
| 未配置 | `⚙` | `var(--warn-d)` |

### 颜色规则

- 空状态的背景：**透明**，不要给空状态加额外的背景色块
- 文字颜色：标题 `var(--t0)`，描述 `var(--t2)`，辅助 `var(--t3)`
- CTA 按钮：首次使用用 accent 色（引导），错误用 ghost 按钮（重试）
- 错误图标背景用 `var(--dan-d)`，未配置用 `var(--warn-d)`

## 各页面空状态文案

### 回测管理

| 类型 | 标题 | 描述 | CTA | 辅助 |
|------|------|------|-----|------|
| 首次使用 | 还没有回测记录 | 创建你的第一个回测，在历史数据上验证策略表现 | + 创建回测 | 支持 Bar 和 Tick 粒度 |
| 筛选无结果 | 未找到匹配的回测 | 尝试调整筛选条件或搜索关键词 | 清除筛选 | — |
| 加载失败 | 回测列表加载失败 | 无法连接到服务器，请检查网络连接 | 重试 | 错误码: ECONNREFUSED |

### 策略管理

| 类型 | 标题 | 描述 | CTA | 辅助 |
|------|------|------|-----|------|
| 首次使用 | 没有发现策略 | 在策略目录中放入 Python 策略文件，或手动创建一个新策略 | + 新建策略 | 策略目录: `tino/strategies/` |
| 扫描无结果 | 扫描完成，未发现策略 | 确认策略文件继承了正确的基类并包含必要的类装饰器 | ↻ 重新扫描 | 查看文档 |

### 交易终端 — 策略列表

| 类型 | 标题 | 描述 | CTA |
|------|------|------|-----|
| 首次使用 | 暂无运行策略 | 启动策略后将在此显示运行状态 | 前往策略管理 |

### 交易终端 — 持仓表

| 类型 | 标题 | 描述 |
|------|------|------|
| 无持仓 | 当前没有持仓 | 策略开始交易后，持仓信息会自动出现 |

### 交易终端 — 订单表

| 类型 | 标题 | 描述 |
|------|------|------|
| 无挂单 | 暂无挂单 | 当前没有活跃的挂单 |

### Dashboard

| 类型 | 标题 | 描述 | CTA |
|------|------|------|-----|
| 首次使用 | 欢迎使用 QDS | 从创建策略或导入历史数据开始 | 开始配置 |

### Watchlist

| 类型 | 标题 | 描述 | CTA |
|------|------|------|-----|
| 首次使用 | 监控列表为空 | 添加你关注的交易对到监控列表 | + 添加品种 |

## 交互行为

### CTA 按钮

- 首次使用的 CTA 是 **accent 填充按钮**（`border: var(--acc), background: var(--acc-d), color: var(--acc)`），hover 变实心
- 错误重试的 CTA 是 **ghost 按钮**（`border: var(--bd)`），视觉更轻
- 重试按钮点击后显示 loading 态（文字变透明 + spinner），1.5s 后恢复或跳转

### 筛选无结果

"清除筛选" 按钮应该一键重置所有筛选条件并刷新列表，不是弹 modal 让用户手动操作。

### 加载失败

- 显示技术错误码（`ECONNREFUSED`、`TIMEOUT`、`500`），帮助排查
- 错误码用 `var(--t3)` + mono 字体，不要太显眼但要可见

## 禁止的做法

| 禁止 | 原因 |
|------|------|
| 空白页面什么都不显示 | 用户以为系统坏了 |
| 只显示"暂无数据" 没有 CTA | 用户不知道下一步做什么 |
| 用灰色大段文字解释为什么是空的 | 没人读长文字 |
| 用卡通插图或 emoji | 不符合 QDS 的专业审美 |
| 空状态用和有数据时不同的布局 | 从空→有数据时页面不应该跳变 |
| 表格空状态还显示表头 | 空表显示列名很怪（除非表头有筛选功能） |
